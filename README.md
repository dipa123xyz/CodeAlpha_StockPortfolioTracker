# Stock Portfolio Tracker

A simple Python project that calculates the total investment value of selected stocks using manually defined stock prices.

## Features

- Enter stock names and quantities
- Uses a dictionary to store stock prices
- Calculates investment for each stock
- Calculates total investment
- Saves the final result to a text file

## Technologies Used

- Python
- Dictionary
- User Input/Output
- Basic Arithmetic
- File Handling

## Available Stocks

- AAPL - 180
- TSLA - 250
- GOOGL - 150
- MSFT - 420

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python main.py

4. Enter the stock name and quantity.
5. Type `done` when finished.

## Output

The program displays the investment value and total investment and saves the result in `portfolio.txt`.
